# 記事素材

あとで記事にするときの材料置き場。**書きかけの記事はここに置かない** ── ここは素材だけ。

## 置き方

```
docs/writing/
  README.md          この索引
  assets/            動くデモ、図、計測スクリプトなど、記事に貼るもの
  <topic>.md         そのトピックの素材（下の構成に従う）
```

素材ファイルは 1 トピック 1 ファイル。記事そのものではなく、
**記事を書くときに手元にあってほしいもの**を集める:

- 主張と、それを裏づける実測値（数字は必ず出典つきで）
- 試して駄目だった案と、なぜ駄目だったか
- 踏んだ落とし穴と、その症状
- 図・デモへのパス

## 素材はどこから来るか

このリポジトリでは、素材は 3 か所に自然に溜まる。記事を書くときはここを漁る:

1. **`lib/` のコメント** ── 定石・なぜその値か・却下した代案が書いてある。
   実験側（`components/lab/experiments/`）のコメントは薄いので、
   触ったついでに厚くしていく（[../../CLAUDE.md] の方針ではなく、この慣習として）
2. **`docs/superpowers/specs/*.md` の「実装後」節** ── 設計時の値から何が変わったか、
   何を踏んだか、次に触るならどこか
3. **テストの名前** ── 日本語で主張が書いてあるので、そのまま見出しになる
   （例:「velocitySkew は飽和域でも深度の順序を保つ」）
